## Descripción
Proyecto desarrollado en Spring Boot (Java 21) para la Actividad 1. Incluye 2 controladores con 3 endpoints en total para responder peticiones en texto plano y JSON. El proyecto fue probado en entorno local y posteriormente desplegado en el servidor VPS en el puerto 8081.

---

## Endpoints de la API

* `GET /proyecto` - Muestra la identificación del proyecto/instancia (Texto plano).
* `GET /materias` - Retorna un listado simulado de materias (Arreglo JSON).
* `GET /estado` - Retorna el estado del servidor y el puerto en uso (Objeto JSON).
